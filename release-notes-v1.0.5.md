### New Features

* **Browser Extension Session Recovery:** Added background session monitoring and automatic cookie refresh through the browser extension, allowing expired YouTube Music sessions to recover without requiring a manual restart.
* **Startup Recovery Flow:** Added a full-window splash screen with authentication, library scan, playlist loading, synchronization progress, and clear signed-out/reconnect guidance.
* **Stream Preloading:** Upcoming queue tracks now prefetch yt-dlp stream URLs, reducing the delay when advancing to the next track.
* **Structured YouTube Music Integration:** Refactored the YouTube Music backend into dedicated authentication, client, data, parsing, cookie, and playback modules, with separate renderer stores for authentication, library, playlists, UI, and session initialization.
* **Faster Metadata Resolution:** Track durations can now be read directly from raw YouTube Music responses, avoiding unnecessary cache, API, and yt-dlp lookups.

### UI & UX Changes

* **Authentication Settings:** Added browser-extension setup instructions, live connection status, session recovery controls, and a clearer path for reconnecting YouTube Music.
* **Playback Experience:** Improved queue handling, stream refresh behavior, track switching, duration updates, and playback recovery for YouTube Music tracks.
* **Search Responsiveness:** Search input now preserves spaces and updates immediately while heavier library filtering runs asynchronously.
* **Library and Playlist Loading:** Playlist hydration, cover images, and library synchronization now appear more reliably during startup and background refreshes.

### Technical Fixes & Improvements

* **Session Validation:** Sessions are now recovered based on validity instead of timestamps, with stronger authentication-cookie checks and corrected SAPISID hash handling.
* **Cookie Handling:** Centralized browser-extension cookie utilities, filtered cookies for yt-dlp compatibility, and made concurrent yt-dlp requests use isolated temporary cookie files.
* **YouTube Music Reliability:** Fixed stale session handling, sync failures, playlist ID normalization, cache behavior, and recovery-loop bounds.
* **Playback Reliability:** Hardened stream URL resolution and audio playback error recovery, including cookie serialization and yt-dlp session handling.
* **ARM64 Windows Installer:** Forced the compatible 7-Zip BCJ2 filter and enabled ARM64 Windows packaging so the NSIS installer retains the application executable and DLLs after installation.
* **Dependency Updates:** Updated YouTube Music, ColorThief, Electron updater, React tooling, Tailwind, Zustand, and related dependencies; removed unused packages.
* **Development Workflow:** Added an Electron predev build step to prevent the development startup race.

### Documentation & Housekeeping

* Replaced the legacy `LEARNS.md`/`llms.txt` guidance with repository agent instructions, domain context, and issue-tracker documentation.
* Removed the unused OAuth login flow and extracted shared renderer store helpers.
