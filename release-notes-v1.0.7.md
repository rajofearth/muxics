### AppImage updates

* **AppImage update information:** Linux AppImages now embed AppImage-native update
  information (`gh-releases-zsync|rajofearth|muxics|latest|Muxics-*-<arch>.AppImage.zsync`)
  in the `.upd_info` section, and a matching `.zsync` is published next to each
  AppImage. AppImageUpdate, `appimageupdatetool`, Gear Lever, and AppImageLauncher
  can now update Muxics with efficient delta downloads.
* The embedded update information is written in place (no repack), so the
  electron-builder runtime is unchanged. The electron-updater manifest is refreshed
  after patching; Linux in-app updates now use a full download.

## Muxics (packaged by electron-builder)

This release includes builds for macOS (arm64), Linux (x64 & arm64), and Windows (x64 & arm64).

See attached artifacts for installers and archives generated by electron-builder.

- Windows installer is NSIS by default (see electron-builder.yml).
